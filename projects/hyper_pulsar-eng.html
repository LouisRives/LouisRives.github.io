Hyper Pulsar

◆  TOP-DOWN SHOOTER  ·  NEO-NOIR  ·  GAMEMAKER  ◆

✦

Hyper Pulsar is a die-and-retry 2D action game built around precise movement, well-timed parries, and strategic combat. The player takes on the role of an intergalactic bounty hunter tracking targets across different planets, each with its own theme and mechanics. Inspired by Hotline Miami and Katana Zero, the whole thing is set in a brutal, stylized neo-noir universe.

The project got scrapped. Too ambitious for a solo developer during a gap year — which is a completely normal part of making games, even if it stings a bit.

That said, it's probably the project I learned the most from. Starting from scratch in GameMaker, I had to figure out how to actually build a game: code architecture, state management, enemy AI, combat systems, pixel art, animation. 150+ hours of really understanding how games work under the hood, not just on the surface.
